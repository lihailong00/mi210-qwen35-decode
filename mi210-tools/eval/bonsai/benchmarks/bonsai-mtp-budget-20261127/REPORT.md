# MI210 上 Bonsai K=3 的下一步优化

当前服务器在短提示、单请求、贪心生成下达到 142.21 token/s。单独计时的 425 个验证轮平均交付 3.012 个 token，每轮 21.58 ms。保持相同接受率，200 token/s 对应每轮 15.06 ms，差距为 6.52 ms。主模型验证用 18.12 ms，草稿用 2.78 ms，状态追赶和其余时间合计 0.69 ms。

## 共享输入的实际范围

对实际 llama-server 进程只读记录权重名、输入张量、数据地址、形状及行距。四次完整的四列图构建得到同一顺序。401 个 Q2_0 投影对应 257 组连续输入：64 对 FFN gate/up，48 对注意力 QKV/gate，16 组注意力 Q/K/V，以及 129 个单独投影。每轮合计存在 144 次重复量化。针对这些共享源，复用应限于同一次图执行内，保持张量和变换身份、布局及生命周期一致。单看内存地址会受工作区复用影响。

20 个完整验证轮的内核追踪显示，257 组都存在连续的符号乘法、1024 点 Hadamard 和 Q8 量化操作。符号乘法中位合计 1.15 ms，正向 Hadamard 1.15 ms，全部 401 次 Q8 量化 1.79 ms（其中重复部分约 0.64 ms），401 次矩阵内核 11.81 ms。GPU 追踪与正常服务阶段计时来自不同运行，不能直接把追踪总和从服务耗时中相减。

## 隔离验证

在同一张 MI210 上，用实际 401 个形状、分组和顺序构建 HIP 图。模拟权重采用原 Q2_0 四行交错布局，互不重叠，共 7,199,539,200 字节。比较独立工作的符号乘法、Hadamard、Q8 准备和四列矩阵内核与各候选实现，保持每个投影的输出布局和 FP32 归约次序。每种配置预热，交替顺序取九轮中位数。全部四个候选与隔离基准的 16,590,848 个输出逐位相同。表中为每轮投影子图的 GPU 时间。

| 实现 | 单个输入工作区 | 257 个独立输入工作区 |
|---|---:|---:|
| 基准，分别启动符号乘法、变换、逐投影量化和矩阵核 | 13.18 ms | 13.25 ms |
| 仅复用 Q8，变换和所有投影仍独立 | 12.83 ms | 12.91 ms |
| 融合符号乘法、Hadamard 和 Q8，每组准备一次，各投影仍独立 | 12.27 ms | 12.35 ms |
| 复用 Q8 且合并同输入的投影，符号乘法与变换仍分开 | 11.91 ms | 11.98 ms |
| 融合并复用输入准备，合并同输入的投影 | 11.45 ms | 11.52 ms |

综合方案在两种工作集下都节省约 1.73 ms。分组内的投影仍从各自权重指针读取数据，各写各的输出，不需要再复制、拼接权重。重放使用合成数据，不包含注意力、采样、草稿和服务器调度。若收益完整传递到每个平均服务轮次，约为 152 token/s，距 200 仍差 4.79 ms/轮。生产验证需要在同一组提示上交替开关、检查逐 token 输出和最终每轮耗时。

## 其他候选的预算

单独重放矩阵部分，原内核为 11.20 ms，分组矩阵核为 10.51 ms。在相同顺序下只流式读权重并做校验、不做推理为 6.27 ms，这给出了当前启动粒度下的读性能参照。另一种代数等价内核用无符号权重码配合激活和修正，结果逐位相同，但只从 11.20 降到 11.04 ms，且该计时假定激活和已准备好。

单独标记草稿阶段的 34 个范围，每个都含 105 个 GPU 内核。最后 20 个范围中，三次词表 Q2_0 投影合计约 0.99 ms，21 次 Q4_0 矩阵向量运算合计约 0.90 ms。若未来将这两项耗时各减少四分之一，单轮约再节省 0.47 ms。该估算尚未经过端到端验证。

生产源码和运行库沿用四行交错版本。本次新增的是独立诊断、微基准和报告。
