# MI210 上 Bonsai 27B 的 MTP 验证优化

单卡 MI210 上，K=3 的单请求综合 decode 从 89.84 提升到 119.41 token/s（+32.9%），相对关闭 MTP 的 79.01 token/s 提高 51.1%。

| 设置 | 综合 decode（token/s） | 三次独立启动（token/s） | 每次草稿接受数 / 提议数 |
|---|---:|---|---:|
| 关闭 MTP | 79.01 | 79.38, 81.35, 76.45 | — |
| K=2，原 DP4A | 97.63 | 98.57, 98.17, 96.18 | 762 / 1020 |
| K=2，新 MFMA | 107.85 | 108.09, 107.58, 107.89 | 762 / 1020 |
| K=3，原 DP4A | 89.84 | 89.07, 90.42, 90.03 | 848 / 1272 |
| K=3，新 MFMA | 119.41 | 120.38, 119.80, 118.09 | 848 / 1272 |

每种设置在同一版 llama-server 上独立启动三次。每次预热后依次运行英文续写、Python、中文解释、算术和 JSON，各生成 256 token。表中的吞吐按全部生成 token 除以总 decode 秒数计算，排除 prefill 和启动时间。单请求、贪心、seed=1、关闭提示缓存、8192 context、4096 batch/ubatch、FA 开启、F16 KV。各次生成都与同一无 MTP 基准逐 token、逐文本相同。

| 提示 | 关闭 MTP | K=3，原 DP4A | K=3，新 MFMA |
|---|---:|---:|---:|
| 英文续写 | 80.22 | 67.50 | 88.66 |
| Python | 80.27 | 106.84 | 142.32 |
| 中文解释 | 78.91 | 78.97 | 105.60 |
| 算术 | 78.73 | 102.09 | 136.62 |
| JSON | 77.00 | 110.80 | 147.57 |

## 验证轮耗时

同一组五条请求，各配置都用了 425 轮交付 1,280 token，每轮平均 3.012 token。以下为单独开启阶段计时的测量，单位为 ms/轮。

| 阶段 | 原 DP4A | 新 MFMA |
|---|---:|---:|
| 主模型验证 | 30.08 | 21.60 |
| 草稿生成 | 2.82 | 2.80 |
| 草稿状态追赶 | 0.20 | 0.19 |
| 其余时间 | 0.51 | 0.49 |
| 总计 | 33.62 | 25.08 |

按 rocprof 中 20 个完整四列验证轮次统计，每轮 401 次 Q2_0 矩阵内核的合计耗时中位数从 23.87 ms 降到 15.72 ms。新路径的激活量化内核另用 1.80 ms。硬件计数器另取 15 个完整轮次，每轮读取约 7.25 GB，读取带宽从 290 升到 442 GB/s。这张卡既有的 4 GB 连续读实测为 1,361 GB/s；两项测试的指令和访存模式不同。

## 较长输入与 prefill

单条 4,096-token 输入续写 256 token，关闭 MTP 为 76.01 token/s，K=3 原验证为 98.89，新验证为 129.07。三种配置输出逐 token 相同。该条提示接受 183/214 个草稿 token，属于一次单独抽查。

独立的 llama-bench pp8192（ubatch=4096，3 次）为 1957.3 → 1954.2 token/s。此次只优化 3/4 列验证，8K prefill 使用既有的大矩阵路径。

## 实现和正确性

新 HIP 内核在 gfx90a 上用 INT8 MFMA 一次计算四行、四列的整数点积，多个行组共用激活。F32 激活一次量化为适合矩阵指令的 Q8 布局，FP16 缩放舍入及 FP32 累加顺序复用现有单 token 语义。权重沿用已有的无损 Q2_0 重排缓存。两列、小矩阵、其他架构和未支持的融合继续走既有路径。

34/34 项 Q2_0 算子测试通过。独立逐列对齐测试覆盖六种 K、2/3/4 列、连续输入和带偏移及行间距的输入，并包含全零块和舍入边界。27,648 个 F32 输出与逐列执行逐位相同。Qwen IQ3_S 的 128-token 原始 logits 哈希与之前相同，tg128 为 80.13 token/s。

在此次构建的 llama-server 上使用 `--spec-type draft-mtp --spec-draft-n-max 3`。MFMA 在支持的形状上默认开启，用环境变量 `GGML_MMVQ_Q2_0_MFMA=0` 可切回上一版 DP4A 验证。此前总开关 `GGML_MMVQ_Q2_0` 与多列开关 `GGML_MMVQ_Q2_0_VERIFY_BATCH` 继续生效。

实测范围为单张 MI210、单并发、贪心生成。代码在服务器的 `bonsai-q2-20261127` 工作目录，尚未提交。
